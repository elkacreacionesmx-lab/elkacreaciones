# # Elka Creaciones

## Estructura

```text
elka-creaciones-web/
├── index.html
├── README.md
└── assets/
    ├── css/styles.css
    ├── js/main.js
    └── img/referencia-diseno.png
```

## Uso

Abre `index.html` directamente o utiliza la extensión Live Server de Visual Studio Code.

## Cambios necesarios antes de publicar

- Sustituir teléfono, correo, WhatsApp y ubicación.
- Agregar los enlaces reales de redes sociales.
- Cambiar los bloques gráficos por fotografías reales optimizadas en WebP.
- Conectar el formulario a un backend, Formspree, EmailJS o Laravel.
